SyndromeOS

A 64-bit x86_64 kernel built from scratch, handling the transition to Long Mode, 4-level paging, IDT/GDT, and custom interrupt handling.

  • Long Mode & Paging: 4-level hierarchical paging (PML4) managing identity-mapped RAM and 48-bit canonical addressing.
  • Hardware Descriptors: Custom 64-bit GDT with TSS and 256-entry IDT handling CPU exceptions, PIC/APIC timer IRQs.
  • Subsystems: Bitmap physical frame allocator, UART 16550 serial console driver, and an interactive kernel shell.

Computer Graphics / Parallel Computing

Simple-RayTracer

A multithreaded CPU ray tracer featuring Bounding Volume Hierarchy (BVH) acceleration, physically-based materials (diffuse, dielectric, metal), and an interactive Dear ImGui scene editor.

  • BVH Acceleration: Spatial partitioning using Surface Area Heuristic (SAH) for logarithmic O(log N) ray-primitive traversal.
  • PBR Materials: Physically accurate Lambertian diffuse, metallic reflections with roughness, and dielectric glass refractions (Schlick's approximation).
  • Interactive ImGui: Live camera orbiting, progressive sample accumulation, thread workload telemetry, and runtime scene tweaking.
